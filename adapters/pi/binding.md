# Pi runtime binding

Keep the main session as coordinator. Use `ideascientist_agent` for one fresh role task at a time. It starts a native Agent with an empty message history and the selected parent model, thinking level, and model registry. It never copies credentials or parent messages. Pass absolute plugin_root and run_directory, T task_id, target_ids, exact input_files and output_files, instruction, cutoff, already reserved allowances, and readers. Each readers entry contains paper_id, bibliographic identity as a metadata string, exact source URL or local path, 1–5 goals, and digest_path. Include its P ID in target_ids. Never paste a source body into instruction or identity.

The dispatcher adds `existing_output_files` to the worker message, listing owned outputs present at dispatch. Read an existing digest before updating it. For an absent output, create it without issuing a read. Every model-issued file operation still runs through the host hooks; a failed or denied read remains blocked.

The native worker has only its role capabilities. Host file and research tools run through `ctx.executeTool`, retaining host argument validation and permission hooks. Reads and writes use explicit packet path allowlists, including canonical schema and contracts. Baseline receives no workflow, discovery, fetch, or reader tools. Innovator receives no baseline. Reader can fetch only a registered exact source and writes one P digest. No shell is available to specialists. These guards supplement the prompts; they do not constitute an operating-system sandbox.

Use `ideascientist_search` for public Crossref metadata discovery, `ideascientist_metadata` with a source arXiv ID or abs/pdf URL for exact arXiv identity, and `ideascientist_fetch` for registered public HTML or text. The registered metadata tool calls the bundled Python helper with a fixed argument array and no shell. It returns only canonical identity and provenance, never abstracts or bodies. It is exposed only to discovery-capable workers with a positive search reservation; reader, baseline, and coordinator workers receive no metadata tool. Keyword searches and metadata resolutions share one finite counter, including failed or denied attempts. Metadata calls run through `ctx.executeTool` with host hooks and cancellation, so denial remains blocked. Python 3.10 or later is required. They require no API key and run through the same permission hooks. Search is metadata only with limited coverage. Fetch cannot parse PDF, log in, or render JavaScript. Do not substitute an abstract for a mechanism claim. Missing full text blocks that claim. Host tools can replace these tools through IDEASCIENTIST_PI_SEARCH_TOOL and IDEASCIENTIST_PI_FETCH_TOOL set before Pi starts. The named tools must be callable, and fetch must accept a `url` argument. The packet cannot select tool names. No direct research tool executes in the coordinator context.

Registered specialists use `registered_reader` with a paper_id from their packet. This is a fresh native reader context, bounded by the already reserved reader allowance. It cannot nest another reader or role. Sequential execution prevents overlapping same-paper edits. On errors, denial, cancellation, or timeout, the adapter returns blocked. The coordinator must not replace a blocked reader by opening its source or creating a digest itself; retry the authorized isolated reader route or retain blocked. Reservations remain spent. Coordinator retains partial artifacts and validates receipts before advancement.

Workers must return only one JSON completion object. Use {"status":"done","artifact_paths":["<owned absolute output>"]}, {"status":"needs_registration","discovery_path":"<owned absolute discovery>"}, {"status":"reader_relay","request_path":"<owned absolute request>"}, or {"status":"blocked","reason":"<honest reason>"}. No raw source, free-form analysis, or citation excerpts appear in completion. Successful model termination is not artifact validation. The coordinator applies the canonical checker before advancing.

For check, use the coordinator's authorized bash tool to run Python 3 with the bundled scripts/check_artifacts.py and safely quoted absolute run directory as separate arguments. Report its actual exit status. When shell execution is unavailable, apply documented manual checks and label them manual.
