# Codex runtime binding

Keep the main session as coordinator. Resolve the plugin root from the installed skill file by ascending four directories from its containing skill directory. Verify references/workflow.md and references/artifacts.schema.json exist there. Pass the absolute root and run directory in every packet. Use the current session's model, provider, approval policy, and sandbox. The plugin does not register custom agents or change user configuration.

Inspect the exposed native multi-agent tool schemas. With V1, spawn_agent uses a message and fork_context=false. With V2, spawn_agent uses task_name and message with fork_turns="none". Use a generic default worker type and do not override model or reasoning effort. Supply the canonical references/roles/<role>.md path, this binding path, explicit allowed input/output paths, task and target IDs, registered source identities and goals, cutoff, and spent allowances. Do not paste the coordinator history, raw sources, candidate into baseline, or baseline into innovator. Await the native completion, then close or finish the worker according to the exposed protocol. Execute calls sequentially.

Use coordinator reader relay by default because nested worker support and depth vary. A substantive role discovers metadata, writes discoveries/Tnnn.json, and returns needs_registration. Main registers exact versions and re-invokes the role. If registered answers need reading, the role returns reader_relay with exact registered metadata, goals, P ID, and digest path. Main dispatches a fresh generic worker reading references/roles/paper-reader.md, then re-invokes the specialist with only structured digest paths and a new task. The original reader reservation covers that relay and is never charged twice. Do not modify max_depth or agent configuration to enable nesting. If native spawning is unavailable, stop blocked.

Metadata search maps to native web search Search. Exact arXiv metadata resolution uses the native command tool, such as exec_command, for `python3 <absolute-plugin-root>/scripts/resolve_metadata.py <arxiv-ID-or-abs/pdf-URL>`. This fixed helper command with one safely quoted source argument is a permitted metadata capability under native sandbox and approval hooks. It emits only exact identity and metadata provenance, never abstracts or bodies. Each attempt consumes one reserved search. Await command completion before using its JSON; a blocked result or denied command cannot become a resolved identity. Registered body retrieval maps to OpenPage, with FindInPage for locators when available. Cached search or unavailable provider capabilities limit coverage. A historical cutoff cannot prevent search snippets from revealing later work. Reader may read an authorized local file through native file tools. When PDF parsing or exact-version access is unavailable, preserve an honest abstract or unavailable access level and block unsupported mechanism claims. Search is discovery metadata only in specialists. Coordinator never opens source bodies.

Generic workers may inherit native tool availability. The role's permitted semantic capabilities and explicit file ownership are prompt restrictions under native sandbox and approval hooks. They are not a security sandbox. Paper-reader uses only registered source fetch, local source read, and its digest write. Blind-baseline uses only allowed problem, gap, near-miss digests, schema, and its output. Specialists use metadata search, the fixed metadata helper, artifact read/write, and coordinator reader relay. No general command execution or unrestricted source fetch. Codex file access may be exposed through exec_command or an equivalent native command tool. Use it only for safely quoted read, existence checks, and writes to explicitly allowed files, or use apply_patch for owned artifacts. This is the runtime file capability, permitted even when a canonical role forbids general shell work. Do not execute research code, install dependencies, broaden paths, or use commands to fetch unregistered sources. Run the canonical Python checker only through the coordinator's authorized command tool, with separately quoted absolute arguments.

Return only done plus owned artifact paths, needs_registration plus discovery path, reader_relay plus the registered metadata request, or blocked plus reason. No raw text. Native errors, denied tools, abort, and timeout are blocked, never done. Main validates canonical receipts before advancement and preserves all spent reservations.
